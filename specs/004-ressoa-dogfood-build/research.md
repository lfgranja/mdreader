## R1: Single offline voice (fixed at plan time)

- **Decision**: Fix **`pt_BR-faber-medium`** (Piper VITS, mono 22050 Hz, CC0) as the sole bundled voice. Pure offline; zero network voice code ships.
- **Rationale**: Already embedded and proven end-to-end: `crates/adapter-synthesis/assets/voices/pt_BR-faber-medium/` (onnx 63 MB, blake3 `feb0b4…26cbd`, `.onnx.json` `sample_rate=22050`, `tokens.txt`, `espeak-ng-data/` 19 MiB, `MODEL_CARD`, `PROVENANCE.md`); `crates/adapter-synthesis/src/synth.rs` (OnceLock load-once, `num_threads=1`, no network fetch); bundling `src-tauri/tauri.conf.json` `bundle.resources` → APK `assets/voices/…` → `crates/adapter-synthesis/src/android_assets.rs` (`extract_voices` + `.extracted` marker) → `synth::set_asset_dir`; manifest via `crates/adapter-synthesis/build.rs`. Licence CC0 per constitution Licence Policy + TTS Engine Registry (`sherpa-onnx` + Piper pt-BR = offline default, Principle IX). `reg.rs` `REGISTERED_TIERS=[OfflineDefault]` + `is_selectable` admits only it; stand-ins are `TestDouble` fixtures, never selectable. Handoff mono f32 22050 Hz enforced by `engine-core/src/format.rs` (`check_handoff`: mismatch → `RateMismatch`/`ChannelMismatch`, never silent resample); rate stretch is engine-contract pitch-preserving op (`trait_.rs` `set_rate`, `PITCH_TOLERANCE_CENTS=50`), player selects rungs only (`crates/player/src/rate.rs`).
- **Alternatives considered**: `cadu`/`jeff` (also CC0) — rejected, no measured intelligibility win for a full coordinated edit (download + `PROVENANCE.md` + blake3 + `ASSET_ROOT`/`build.rs`/`tauri.conf`); `edresson` — rejected, CC-BY-4.0 attribution excluded by constitution; runtime switching / second voice / cloud fallback — rejected, spec fixes exactly one voice, `is_selectable` already false for cloud tiers.

## R2: Document ingest (FR-018 + FR-008, Option C hybrid)

- **Decision**: Custom Kotlin `ACTION_OPEN_DOCUMENT` intent in `android-shell/` + transient BLAKE3-keyed snapshot under `filesDir`; Rust keeps hash/parse/synthesis authority. No Tauri dialog/fs plugin.
- **Rationale**: Reuse-ready: `crates/session/src/fingerprint.rs` (`blake3-256` content identity), `crates/session/src/store.rs` (`BookmarkStore::{put,get,delete}` atomic single-row tx keyed `[u8;32]`), `crates/session/src/offer.rs` (3 s deliberate-pause vs explicit-resume split), `crates/doc-structure/src/lib.rs` (section-boundary provider). Verified gap: zero picker/URI/snapshot code — `src-tauri/src/lib.rs:play()` takes in-memory `document: String`; Kotlin mirrors cover only focus/routing/residency/mirror. Placement follows constitution (Rust owns synthesis/position, Kotlin owns platform surface): Kotlin owns picker intent + `ContentResolver.openInputStream` + snapshot write at `filesDir/snapshots/<blake3-hex>.{md,txt}` (transient, session-scoped; synthesis reads only this file; trimmed on new pick / Stop / document-end); flags `FLAG_GRANT_READ_URI_PERMISSION | FLAG_GRANT_PERSISTABLE_URI_PERMISSION`, `takePersistableUriPermission()` best-effort in `try/catch(SecurityException)` (failure still reads one-shot grant, re-prompts next open); MIME filter `text/markdown` + `text/plain`; re-hash-on-open (bytes → `fingerprint()` → `store.get` → match = resume offer, mismatch = `0.0` no offer); moved/renamed/revoked (`SecurityException`/`FileNotFoundException`) → re-prompt same picker → hash-match restore (SC-005).
- **Alternatives considered**: Tauri dialog/fs plugin — rejected, no persistable SAF grant control on Android + supply-chain surface; persisted-URI-only (no snapshot) — rejected, revocation kills offline synthesis, violates "synthesize from snapshot"; snapshot-only (no URI) — rejected, loses freshness check, spec mandates hybrid.

## R3: Position persistence cadence (FR-007, Option C tiered hybrid)

- **Decision**: Tiered hybrid, durable interval **20 s fixed** (within the FR-007 15–30 s envelope); persisted cursor = last-spoken atomic single-row tx; sentence-start snap-back + 5–10 s context cue; replay caps 30 s (interruption) / 60 s (kill/power-loss).
- **Rationale**: Reuse-ready: `crates/player/src/position.rs:PositionClock` (`on_audible_progress` only, `stored_basis` trailing ≤ `REWIND_CAP_SECS=30.0`, `REWIND_FRACTION=0.05`, `snap_to_boundary` cap-precedence); `crates/player/src/rewind.rs:cursor()/resolve_resume()` (`min(0.05×paused,30)`, containing-sentence-start snap, mid-word forward-snap, degrade to raw cursor never doc start); `crates/player/src/resume.rs` (3 s window); `crates/session/src/store.rs:put()` (atomic/crash-safe); `offer.rs` end-kind routing. Verified gap: no cadence wiring — `put()` exercised only from tests, no heartbeat/periodic commit, no `put` on pause/focus-loss/device-removal/section-change/stop/background in `cli.rs` / `src-tauri/src/lib.rs:dispatch_intent`. 20 s justification: FR-007 allows 15–30 s; worst-case loss = one interval; 20 s keeps worst loss + snap-back + cue inside the 30 s interruption budget with margin, divides the 60 s kill cap evenly, halves write amplification vs 15 s (~3 single-row tx/min, negligible). Tx: `put(fingerprint, StoredPosition{offset_secs: clock.position_secs() /* last-spoken, never buffered-ahead */, first_yield_ms /* cumulative */, end_kind})`; durable on 20 s heartbeat while Playing + every pause, focus-loss, `BecomingNoisy`/`DeviceDisappeared`, section-change, Stop (then `delete`), app-background, `DocumentEnd`; in-RAM tick ~1 s; non-durable commit per sentence-end/5 s feeds snap-back only.
- **Alternatives considered**: 15 s — rejected, 2× write rate for no budget gain; 30 s — rejected, zero margin for snap-back + cue under the 30 s cap; buffered-ahead cursor — rejected, violates "last-spoken, never buffered-ahead".

## R4: Progress computation (FR-013, Option 3 hybrid)

- **Decision**: Bar = content-offset fraction (`consumed_units / total_units` parsed units); label = `Section k of N + position %`; determinate only when section count + total units both known at session start, else indeterminate for the whole session (no mid-session flip, no backward jump; freeze-then-drop on re-parse; zero sections → indeterminate + no title); audio-duration estimates never feed it; no seek without true random-access offset.
- **Rationale**: Existing `crates/player/src/surface.rs` already fixes determinacy at session start and resolves section as most-recent-passed heading else `None` (never forward-looking) — only the unit changes (current total is time-based `marked_document_total`; 004 requires parsed-content units from `doc-structure` + `adapter-synthesis::chunk::split_document`). Keeps `None`-section, non-dismissable-while-playing (`Dismissal`), `TRANSIENT_DISMISS_MS=3000` rules. Matches DESIGN-SONA determinate-iff-known-at-start.
- **Alternatives considered**: Time-based progress — rejected, violates "audio-duration estimates never feed it"; mid-session determinate flip on late parse — rejected, spec mandates whole-session indeterminate + freeze-then-drop.

## R5: Failure/reason closed set (FR-005, Option O2 medium closed 7±1)

- **Decision**: Keep the three existing closed taxonomies untouched; unify the 8 product reasons (`FocusDenied, FocusDelayed, PermanentLoss, TransientPaused, DeviceRemoved, VoiceUnavailable, FormatUndeliverable, DecodeFailed`) as a **surface/diag-level reason enum** (new `crates/player/src/interruption.rs` or diag kind) mapping N:1 onto them. No `Other`/`Unknown`, no `_ =>` (gate 7). `DecodeFailed` reuses `EngineError::Unreachable` on the wire (diag logs `decode_failed`), keeping the 7-member engine taxonomy stable (no semver bump).
- **Rationale**: Existing coverage all closed/exhaustive: `crates/player/src/focus.rs` (`FocusOutcome` 3, `FocusIntent` 9, `FocusGrant` 3, `classify` 9 arms, `supersede_flags` 3×3, latest-wins tracker); `FocusMirror.kt:77-125` (complete `AUDIOFOCUS_*` → `duckable_transient`/`silence_demanding`/`permanent_loss`/`regained`, `GRANTED`/`DELAYED`/`FAILED`); `routing.rs` + `RoutingMirror.kt` (`BECOMING_NOISY` + `onAudioDevicesRemoved`, ≤1 s); `engine-core/src/closed.rs` (`EngineError` 7) + `adapter-synthesis/src/failure.rs` (10 conditions → 7, exhaustive) + `src-tauri/src/failure.rs` + `surface.rs` (1:1 reason map, `Focus3s` vs `FailurePersistent` expiry split). Mapping: `TransientPaused` splits by focus class — `MAY_DUCK` (`AUDIOFOCUS_LOSS_TRANSIENT_MAY_DUCK`)→`DuckableTransient` (duck to 0.20 keep playing, restore on `GAIN`); non-duckable `TRANSIENT`/call/alarm→`SilenceDemanding` (pause + 3 s reason, never auto-resume); `FocusDenied`→`Refused→Err(StartRefused)` (pause + 3 s, never auto-resume); `FocusDelayed`→`Deferred→Ok(false)` (zero-audio hold); `PermanentLoss`→pause + 3 s latest-wins; call/alarm transient→`SilenceDemanding` pause + 3 s; `DeviceRemoved`→`Pause` ≤1 s + 3 s; `VoiceUnavailable`→`InitFailed` persistent; `FormatUndeliverable`→`RateMismatch`/`ChannelMismatch` persistent; `DecodeFailed`→wire `Unreachable`, diag `decode_failed` persistent. Each maps 1:1 to a ≤8-word lock-screen line + distinct earcon + logged failure name.
- **Alternatives considered**: Extend `EngineError` to 8+ — rejected, forces coordinated edit + semver bump for zero trial evidence; single flat 8-enum replacing focus/grant/engine taxonomies — rejected, destroys supersede matrix + granted/deferred/refused trichotomy + 3 s-vs-persistent split; catch-all — rejected, Principle VII / gate 7.

## R6: Earcon + haptic confirmation (FR-016, Option B + fallback)

- **Decision**: Synthesize all earcons in **Rust as procedural mono f32 @ 22050 Hz** in new `crates/player/src/earcon.rs`, played through the existing `CpalBackend` on a **duck-exempt short-mix bypass** (skips `SampleQueue::gain` scaling); trigger + lock-screen mirror publish is one Rust call; haptics fire **Kotlin-side** in `MediaMirror.publish()` via `Vibrator`/`VibrationEffect` driven by the Rust reason (silent/DND path). No audio assets.
- **Rationale**: Rust owns synthesis + PCM (`backend.rs` exact mono f32 22050 fail-closed; `engine-core/format.rs:DeclaredFormat`); SC-035 forbids Kotlin computation (mirrors forward-only); existing duck actuator (`SampleQueue::consume_into` scales every audible sample; `DUCK_GAIN 0.20`) would duck earcons without a bypass — hence same stream/same clock, bypass flag, position clock counts speech samples only (earcon 5138–11025 samples must not move bookmark). Duck-exempt ≠ pre-empt: no `AudioFocusRequest`, ≤500 ms at full gain even while ducked, dropped/re-fired post-`GAIN` if a pause stands. Grammar reused verbatim from `DESIGN-SONA/components.md:53-61` + `tokens.md` (Adagio C5→E5 / Andante E5→C5 120 ms sine, Allegro tick, Ostinato double-tick A5, Unison 880 Hz/60 ms) with one transposition: failure D3 (~146 Hz) → **E4 (~330 Hz square + minor-2nd dissonance)** to satisfy FR-016 300–2500 Hz while keeping the abstract-dissonant warning/failure pair distinct from caricature play/pause/skip. 1:1 lock-screen mirror rides the same Rust publish (`transientReason` + `AutoDismiss(3000)`); haptic patterns distinct per action (`VibrationEffect.createOneShot`, `VIBRATE` permission) work muted/DND (not on `STREAM_MUSIC`); no vibrator/`SoundPool`/`ToneGenerator` code exists today — insertion point `MediaMirror.publish()/buildSurface()`.
- **Alternatives considered**: `SoundPool` + bundled `.wav` — rejected, binary-asset drift + resampling + not CLI-drivable + violates no-asset rule; `ToneGenerator` — rejected, fixed DTMF freqs, rides ducked stream, can pre-empt nav; Kotlin/Oboe second stream — rejected, second clock, violates single authority.

Matches SC-008 (30-day/10 MB, zero prose).
- **Alternatives considered**: In-app surface / network upload — rejected, FR-017 forbids both; spoken interruption announcement — rejected, FR-005 mandates earcon + 3 s text, no TTS announcement.
